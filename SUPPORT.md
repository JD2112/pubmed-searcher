## ❓ Frequently Asked Questions (FAQ)

### Where do I get an API key for Chanakya AI?
- **Groq API Key (Recommended, ultra-fast & free)**: Obtain a free key from the [Groq Console](https://console.groq.com/keys).
- **Google Gemini API Key**: Obtain a key from [Google AI Studio](https://aistudio.google.com/).

### Where is my API key stored?
Your API key never leaves your computer; it is stored solely in your browser's private `localStorage` and sent directly to the official provider endpoint via HTTPS.
